# Axiom landing page

Static site for the Axiom iPhone app (AGL Labs LLC), served by GitHub Pages at https://klustre21.github.io/axiom-app/.

- `index.html` — the landing page and the source of truth for copy. At launch, point the two "Coming soon" buttons at the App Store listing.
- `press.html` — press & creator kit: descriptions, fact sheet, footage, brand, creator rules.
- `llms.txt` — plain-text product summary for AI tools (Fastlane and similar) that read the site.
- `media/` — real app footage. Clips re-recorded on 11 Oct 2026 after the widget redraw (Open Book stage + Code Lab); `axiom-tour.mp4` is a 24 s full-screen tour from real Originals. `lesson-complete.mp4` is from 26 Sep (quiz screen unchanged since).
- `img/og.jpg` — 1200×630 social card (11 Oct 2026).
