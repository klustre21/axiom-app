Gift cards

Print Axiom gift cards

Eight business-card-size cards (3.5 × 2 in) per US Letter page, with light crop marks for cutting. Each card carries the offer code and a QR code that opens App Store redemption.

There's no code in this link yet, so the cards show YOURCODE and the QR codes won't redeem anything. Add your offer code under “Card details” before printing.

  1. Print on US Letter at 100% scale (“Actual size”), margins Default or None.
  2. Turn on Background graphics so the code pill prints in yellow.
  3. Card stock (80–110 lb cover) feels best, if your printer takes it.
  4. Cut along the crop marks: 3 vertical cuts, then 5 across.
  5. Scan one QR code with your iPhone before handing them out.
Card details

One code fills all eight cards. For one-time codes, paste several separated by commas: each gets its own card, eight per page.
