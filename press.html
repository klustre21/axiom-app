In one line

Axiom turns any question into an interactive lesson you learn by doing: drag it, predict it, run it.

Short description (50 words)

Axiom is an iPhone app that builds an interactive lesson from any math, physics or programming question in about a minute. Instead of a wall of text or a video, every page asks you to act: predict the answer, then run the simulation or the code and see whether you were right.

Longer description

Most AI tutors hand you a paragraph. Axiom hands you something to do. Ask how the Large Hadron Collider finds particles and you get a collider to run. Ask why two launch angles land in the same place and you get a launcher to fire. Ask how recursion works and you watch the call stack wind up and unwind, line by line, after you've predicted the answer. Each lesson runs about 15–18 pages: an intuition, worked examples, pages you try yourself, and mastery checks. Alongside lessons built from your own questions, Axiom ships more than 60 hand-written Axiom Originals in math, physics and programming that open instantly, work offline and never use a credit. Axiom is made by AGL Labs, a one-person studio in St. Petersburg, Florida.

What makes it different

  • You do it, you don't read it. Every page asks you to act: drag, fire, tune, step through.
  • Predict first, then see. You commit to an answer before the simulation or the code runs, which is what makes an idea stick.
  • Built for understanding, not homework answers. There's no photo solver. It explains why, so it's something parents and teachers can recommend.
  • Hand-built depth as well as AI breadth. 60+ Originals are written and checked by hand. Generated lessons pass automated checks: quiz answers re-checked, arithmetic evaluated, physics simulations run on real equations.
